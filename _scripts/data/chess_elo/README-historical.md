# Historical FIDE rating snapshots

The pre-2001 snapshots in this directory were converted from the `all.csv` file in [OlimpBase's `elo1967-2001.zip`](https://www.olimpbase.org/Elo/data/elo1967-2001.zip). The source archive credits Mark Weeks, Chess Informant and other contributors, and warns that the historical lists were manually assembled and are not flawless.

This project uses the official FIDE-era lists from **July 1971 through October 2000**, taking the top 100 numeric ratings from each available list. The unofficial 1967–January 1971 material is intentionally excluded. Names and federation codes are retained as supplied; no attempt is made to merge historical spelling variants automatically.

The modern series remains sourced from the Anuj Dahiya mirror (2001–2019) and 2700chess (2020 onward).
