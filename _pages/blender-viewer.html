A small browser viewer for Blender exports.

I have been playing with Blender for a while too. Inspired by Simon Willison's experiments with coding agents and Blender, I asked my agent to create a viewer that makes a Blender-exported model easy to inspect without installing anything.

The viewer includes a demo scene and can open a local .obj export. Drag to orbit, use the wheel to zoom, and keep the model on your own machine: files are read locally in the browser.

Open the viewer in a new tab

Note: This first version accepts OBJ files exported from Blender. The viewer has no external JavaScript dependencies and does not upload selected files.
