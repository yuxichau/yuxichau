Supported files & preview details

Native .blend: choose or drop a Blender project directly. This browser reads the saved mesh geometry, object transforms, material slots and packed image textures using jsblender 0.0.4. Blender 5.x files are best supported. Files with multiple scenes have scene and collection selectors.

Preview fidelity: unapplied modifiers, animation, constraints, procedural materials, curves and rigged geometry are not fully reproduced. Saved mesh geometry is shown; text uses a substitute font. Pack external images in Blender using File → External Data → Pack Resources. No external image files are fetched.

Other files: self-contained, uncompressed GLB models also work. PNG and JPG images support flat-image zoom and pan. A flat render cannot reveal unseen sides of an object.

This page opens directly from disk and works offline. The rendering engine and Blender parser are included; no models are embedded. Your selected files stay in this browser tab. Maximum input size: 100 MB.
