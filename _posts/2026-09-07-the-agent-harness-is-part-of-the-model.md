We need metrics for the [agent harness](https://summarised-essays.pages.dev/blog/2026/09/07/the-agent-harness-can-change-both-cost-and-performance/) as well as for the models it wraps. Metrics already exist for parameterisable end-to-end processes, so if the harness is integral to the result, it deserves equal prominence.
